# EcoTrack V22 — Java 21 + Spring Boot 3 Port

This directory contains the complete Java 21 / Spring Boot 3 implementation of **EcoTrack V22 (TerraLedger Global Household Carbon Tracker)** with pin-to-pin matching 6-Theme Studio CSS, Liquid Glass authentication, kinetic Start Animation, post-login Opening Curtain Sweep Reveal, 8-stream scientific carbon engine (`CarbonCalculationService`), and `gemini-4-hydrogen` Maps Grounding (`MapsGroundingService`).

## Prerequisites
- Java 21 (JDK 21+)
- Maven 3.9+
- Optional: `GEMINI_API_KEY` environment variable for `/api/local-eco-hubs` Maps Grounding

## Run Locally
```bash
cd java-port
mvn spring-boot:run
```
Then open `http://localhost:3000`.
